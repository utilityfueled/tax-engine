# Support

## Where To Ask What

Use the right channel so questions get handled efficiently.

Official hosted Viva La Tax support: `support@vivalatax.com`

### Bug Reports

Open a GitHub Issue when you can provide:
- Expected behavior
- Actual behavior
- Reproduction steps
- Relevant logs or screenshots
- Tax year, form, and state context when applicable

### Feature Requests

Open a GitHub Issue with:
- The problem you are trying to solve
- Why the current behavior is insufficient
- Constraints or relevant filing scenarios

### Security Issues

Do not use public issues.

Follow [SECURITY.md](./SECURITY.md).

### Usage Questions

Use GitHub Discussions if enabled. If not, open an issue and label it as a question.

### Hosted Service Support

For the official hosted Viva La Tax service, use `support@vivalatax.com` for:
- Billing and subscription questions
- Account-access issues
- Privacy-policy or terms questions
- Hosted account deletion requests

## Before Opening Anything

- Check the README
- Search existing issues
- Confirm you are using synthetic data only
