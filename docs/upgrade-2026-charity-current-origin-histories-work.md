# Current loss with complete charitable histories

This package composes actual current receipts and independent regular and AMT prior charitable histories with the existing Form172 current-loss calculation. Both prior NOL histories must explicitly contain no vintages. A newly generated current loss does not itself reduce charitable carry under the rule for an NOL carried into the current year. No AGI, deduction, current loss or carry reduction is entered.

## Source, guide and output binding

The internal `complete_histories` tag comes only from actual complete packets and explicitly empty prior NOL arrays. It is not an input election. Every receipt and original prior vintage retains its category, medium, year, identity, history, use and expiry. The normal regular and AMT ledgers determine their actual selected deductions; the new current loss never fabricates a charitable carry reduction. Original source digests and the private review context reject changed histories, missing packets, changed source kinds and balanced/stale deduction or carry results before template access.

Existing source controls collect both histories. The guide preserves the delivered crypto-donation presence check and original-source-only adjustment callbacks.
