# K-1 semantic deduction labels

The 2025 IRS [partner instructions](https://www.irs.gov/instructions/i1065sk1) and [shareholder instructions](https://www.irs.gov/instructions/i1120ssk) identify cash at the 60% limit as A, capital-gain property at the 30%/20% limits as E/F, and investment interest as H. Those are partnership Box 13 and S-corporation Box 12 respectively. Existing comments/specs incorrectly called the retained capital-gain fields B/C and investment interest D, and described ordinary noncash as Code A cash.

This package corrects those labels and their test references. Mixed-entity audit descriptions now identify semantic categories; existing aggregate keys, saved field names, values and all calculation expressions remain unchanged. It does not recover original statement codes, migrate historical amounts, or establish a raw-document parser defect. Other unsupported K-1 categories remain separate source-method work.
