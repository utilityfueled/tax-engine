# Current ordinary charitable receipt categories

This package completes the current direct-receipt category path for public cash (G), ordinary public property (A), other-recipient cash or ordinary property (B), public long-term investment stock (C), and other-recipient long-term investment stock (D). It requires actual confirmed empty prior history. Both final deduction choices use the same original sources and enacted percentage allowances. Itemization alone can add an eligible current floor amount to carry. No source, category, standard-deduction entitlement, prior balance, or NOL fact is inferred.

Sources refreshed October 25, 2026: [IRC 170(b)(1)(A)–(D), (G), (I), (d)(1)(C), (e), and (p)](https://uscode.house.gov/us/usc/119-120/t26/s170/), [Publication 526](https://www.irs.gov/publications/p526), and [Regulation 1.170A-10](https://www.ecfr.gov/current/title-26/section-1.170A-10). The existing year-specific percentage worksheet supplies the arithmetic. The post-2025 B offset is retained, and the floor is applied in D, C, B, A, G order. A current percentage excess permits the corresponding eligible current-category floor carry under section 170(d)(1)(C). The separate nonitemized ledger uses percentage excess only; the section 170(p) cap does not create carry. Extending that percentage ledger to an explicitly nonitemized return with no standard entitlement remains a derived interpretation, not a published numerical example.

Original receipt valuation now has one shared implementation for Schedule A and current carry candidates. Ordinary property uses the smaller of each receipt's FMV and basis. Private nonoperating foundation investment stock uses basis reduction unless the actual qualified-appreciated-stock fact establishes the statutory exception. Other qualified thirty-percent recipients are distinct from private nonoperating foundations. Unknown recipient classification, holding character, required basis, or stock qualification stays unknown. The candidate reconciles all six exact source amount groups against the canonical worksheet context; it cannot accept a different category or unsupported pass-through amount merely because the total matches.
