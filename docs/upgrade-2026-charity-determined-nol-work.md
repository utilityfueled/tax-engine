# Charitable NOL carry with zero or one affected original excess

This package retains every actual current contribution category and medium, together with each independently supported regular and AMT prior vintage. It calculates their ordinary use first, then compares succeeding NOL carry with all normal charitable excess removed simultaneously. Zero benefit requires no allocation. A positive benefit is supported when only one original excess can be reduced; positive benefit involving multiple excess origins remains guarded.

## Source method and limits

Official sources refreshed on 2026-10-26 are [IRC170(d)(1)(B)/(C)](https://uscode.house.gov/us/usc/119-118/t26/s170/), [Form172 instructions, line26](https://www.irs.gov/instructions/i172), [Reg1.170A-10(d)](https://www.ecfr.gov/current/title-26/section-1.170A-10), [Reg1.172-5(a)(2)(ii)](https://www.ecfr.gov/current/title-26/section-1.172-5), [Reg1.55-1](https://www.ecfr.gov/current/title-26/section-1.55-1), [Reg1.199A-1(e)(5)](https://www.ecfr.gov/current/title-26/section-1.199A-1), and [IRC6102(c)](https://uscode.house.gov/us/usc/119-118/t26/s6102/). The new controls below are derived from those rules; they are not matching published worked examples or independent human qualification.

The normal use calculation retains original recipient classification, per-receipt value, K-1 basis allowance, digital-asset source facts, current-before-prior category use and original expiry. Both charitable histories must be independently complete, even when the NOL or charitable benefit is known zero. An absent history does not become an empty ledger. Existing original-source collectors provide these facts; no AGI, allowance, carry reduction or allocation is entered.

One internal source-bound vector removes all normal excess together. It cannot add a receipt, change its year, category or medium, cross regular and AMT ledgers, or exceed an original amount. The current regular NOL claim remains fixed while the comparison changes modified absorption and succeeding carry. The separate AMT replay retains actual regular AGI, actual deduction selection and actual regular QBI, computes the current signed charitable adjustment, and preserves the actual current ATNOLD during its modified comparison. Each actual source conserves normal use, any noncarryable floor, NOL reduction, expiry and closing carry. The reduction cannot exceed that source's exact excess.

The 2026 itemized branch uses the separately reviewed determined-floor condition: each positive floor hit must be entirely current-year within its affected category. The nonitemized branch retains actual entitlement and the distinct current170(p) deduction. If a current-cash comparison includes both eligible and ineligible receipts, it computes the full feasible range of retained eligible cash from original amounts. It proceeds only when both bounds produce the same reported deduction. It does not choose which recipient's gift was retained. An explicit itemized election has no unused170(p) allocation requirement. Actual2026 calculation, preview and export gates stay closed.
