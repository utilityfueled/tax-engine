# Finite Form 2555 capital-and-services guided originals

This source-intake change exposes the two existing canonical proof methods,
`mixedCapitalServices` and `allForeignCapitalLoss`. It adds no tax formula,
election, generalized allocation, extra source composition, 2026 filing support,
or state qualification.

The official [Form 2555 instructions](https://www.irs.gov/instructions/i2555)
currently display 2026. Their capital-and-services rule requires a reasonable
service allowance and the existing 30% net-profit limit where applicable. The
[December 2025 Publication 54](https://www.irs.gov/publications/p54), chapter 4,
Example 4 retains gross receipts 146,000, expenses 172,000 and a reasonable
allowance 77,000. Its printed 52.74% worksheet produces 90,713 disallowed
expenses, Form 2555 line 45 negative 13,713 and AGI negative 12,287. The guide
records these actual worksheet originals; it does not infer the percentage,
allocate expenses or choose an election. The unchanged canonical tests cover
these rules and the distinct unrounded-fraction rejection.

Both proof shapes start blank. Every original identity, source year, location,
reference, expense, allowance, required confirmation and explicit zero history
has a visible field. The loss allocation method has an unanswered option and
one supported literal method. Explicit confirmation stores a separate deep
snapshot of the entered foreign-income originals. Original edits revoke that
confirmation. Conversion rejects stale snapshots and extra meaning and still
runs the existing independent source resolver. The full federal calculation
separately validates current business, owner, prior history, actual expenses,
allowances, elections and all other activities. No snapshot replaces it.

The sole extra bridge seam normalizes the standard-only empty-source choice
and the false/zero child-credit object with explicit no dependents, only after
a successfully built all-foreign capital-loss proof. A default standard choice
and an explicitly clicked standard radio have the same raw shape; this code
does not distinguish their provenance. Both normalize to the canonical default
for this finite loss/no-other-activity route. The Form1040 financial-line tests match the
existing canonical originals, including the standard deduction and zero taxable
income. An entered itemized source (including explicit zero), nonstandard choice,
combat-pay election, unknown/null child packet or extra original meaning prevents
normalization or stays present so the full-composition guard rejects it. The
canonical schemas, calculations and state guards are unchanged.
