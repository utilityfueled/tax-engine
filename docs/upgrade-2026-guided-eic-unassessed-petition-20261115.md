# Guided original evidence for an unassessed EIC petition

This adds visible source intake for the existing finite 2025 EIC unassessed Tax Court deficiency-petition method. The previous canonical method already accepted a complete original packet; the guided converter discarded that packet and the interview had no controls to enter it. The engine, canonical schema, monetary calculations and filing qualification rules are unchanged.

The source contract remains [the canonical method](../spec/federal/eic-unassessed-petition.yaml). The published [2025 regulation, 26 CFR 1.32-3(b)](https://www.govinfo.gov/content/pkg/CFR-2025-title26-vol1/pdf/CFR-2025-title26-vol1-part1-subjectgroup-id52.pdf) ties deficiency-procedure disallowance to an assessment. [IRC6213(a)](https://uscode.house.gov/us/usc/119-118/t26/s6213/) describes the ordinary notice/petition assessment restriction and its exceptions. The interview establishes none of these facts from an appeal checkbox, elapsed time or an open docket alone.

The filer must enter actual original owner/SSN, source and denied years, linked denial/notice, printed deadline, docket and filed-petition references, filing dates, actual claim/review dates and complete court/account evidence. Ten event fields distinguish unknown, an explicitly confirmed absence through review, and an actual event date. Four factual confirmations plus a final source confirmation remain explicit. The existing strict canonical validator rejects missing, contradictory, extra-key, stale, duplicate and assessed/final proof. Earlier independent denials and another filer's bans retain their existing effect.

Documentary edits clear nested proof and enclosing history confirmations. A newly surfaced confirmation cycle in this added nested-proof workflow is resolved by comparing documentary denial values before clearing the enclosing completeness answer: changing only `sourceFactsConfirmed` does not change facts; changing `allHistoryIncluded` remains documentary. Copying household identities owns its nested records and revokes confirmations; it does not establish petition ownership or fill missing original fields.

The retained first regression loses the complete original proof against the unchanged baseline. A separate DOM regression demonstrates the nested-confirmation cycle. Focused converter/DOM checks then exercise missing and false originals, chronological/identity contradictions, duplicate dockets, unknown versus null dates, copying and mutation isolation, actual source edits, canonical EIC649 on the existing fictional10000-wage fixture, private audit/hosted/provider projections and closed2026 export gates. No tax arithmetic is performed in the UI.

The new browser source contains exactly two cases,1280px and390px. It types the new source fields visibly, tests reload, unknown/false/stale facts and geometry, and keeps all protected action bounds at zero. Only unrelated existing household/current W2 scaffolding is inserted. Collection is evidence of test source; an actual browser qualification run remains required after integration. No new browser services were started by this package.

This engineering package is not qualified human review, an EIC award, Form8862 completion, support for other pending appeals or contested final bans, 2026 full-return qualification, or filing release authorization.
