# Temporary page-only PDF merge components

Status: implemented and independently reviewed; delivery checks follow below. This package does not resolve the remaining remote coverage timeouts by itself.

## Behavior and boundaries

Workspace downloads opt into `pageOnlyTemporaryMerge` for their flattened, explicitly uncompressed temporary components. The pinned pdf-lib 1.17.1 `PDFDocument.copy()` copies completed pages and their resources into a fresh document, omitting unreachable form objects left by flattening. The final workspace merger already copies pages; its final download stays compressed. Ordinary and interactive exports retain the original save path.

The option rejects invalid combinations before template access. Both catalog fields and resolved page widget annotations must be absent before output directories are created. Dangling references left by normal flattening are tolerated. Catalog-level forms and outlines are outside this temporary page-only route. Existing year, source, identifier-redaction and filing gates still run. No tax calculation, dependency, deadline, retry, coverage threshold or readiness gate changes.
