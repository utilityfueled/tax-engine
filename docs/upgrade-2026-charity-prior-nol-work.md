# Original prior charitable carry with regular and AMT NOL

This package supports a 2025 return with no current gifts and at most one actual prior charitable category, medium and contribution vintage in each independently sourced regular and AMT ledger. Both records, when present, retain the same original year/category/medium. Their balances and intervening histories can differ. The original five-year expiration never restarts.

The regular source remains in the existing charitable carryover collector. The NOL history now accepts a complete independent AMT charitable source packet. Retained legacy summary records must reconcile; unknown histories are not converted to zero. Facts-only validation uses actual household/source records without a fabricated income or deduction context. Current gifts, multiple vintages/categories and 2026 prior-floor treatment remain separately bounded.

## Source method

The comparison retains the normal-year treated-paid amount from the original vintage using an internal source-bound tag. No calculated allowance is accepted from input.
- Reg1.55-1(a)/(b) retains actual regular AGI for AMT percentage limits. Independent AMT charity changes current AMTI even when the ATNOL ledger is explicitly empty. Actual regular deduction selection stays fixed in this replay.
- Reg1.199A-1(e)(5) expressly keeps the actual regular199A deduction for current AMTI. The actual AMT charity replay must not re-limit199A. Modified NOL carry contexts remove199A under the existing modification rules.
