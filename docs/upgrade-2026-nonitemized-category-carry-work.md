# Actual nonitemized ordinary category carry

This package extends explicit 2026 standard/nonitemized selection to complete actual current and prior ordinary charitable categories. It computes percentage carry and treated-paid use separately from the current section170(p) deduction. No itemized floor is applied, no prior gift becomes current deductible cash, and no original contribution year changes. It does not establish human tax/form qualification or open the 2026 calculation/export gates.

## Source decision and exact boundary

Refreshed October 25–26: [IRC170](https://uscode.house.gov/us/usc/119-120/t26/s170/), [Reg1.170A-10](https://www.ecfr.gov/current/title-26/section-1.170A-10), and [final2025 Pub526](https://www.irs.gov/publications/p526). The statute supplies the effective2026 B/G ceilings; the regulation and publication supply ordinary category retention, current-before-prior, original-year FIFO and treated-paid use in a standard year. Applying the percentage ledger to an explicit nonitemizer without standard entitlement remains a derived interpretation, as in the earlier pure-G package. These numerical cases are independently derived controls, not published matching2026 examples.

For nonnegative actual contribution base T, current G and prior G share60%T, current first. Current A uses50%T less aggregate G. Prior A reserves current C capped at30%T. Tentative prior C is limited by both the remaining30% capacity and the remaining50% capacity after G/A and reserved current C. The B ceiling then applies amended170(B): lesser of30%T or50%T minus aggregate G, actual A and current C allowable without C's special cap, and prior C treated-paid, plus min(G,10%T). Current B precedes prior B. C is separately limited after G/A/B. D follows all other contributions under its 20%, remaining 30% C/B, and aggregate limits. Its current and prior amounts together also cannot exceed the B ceiling remaining after all current/prior B gifts. All amounts remain Decimal without intermediate dollar rounding.

There is an explicit unresolved interaction between positive tentative prior C and the new B offset. Base100,000, currentG10,000, priorC40,000 and currentB30,000 initially treats priorC30,000 as paid and permits B20,000, but separately limits C to20,000. The old regulation predates this offset. The implementation rejects whenever positive tentative prior C plus reserved current C exceeds that final C allowance. It does not infer which prior balance was consumed or re-age the difference. Current C with prior B remains supported: at base100,000, currentC40,000/priorB30,000 uses C30,000/B10,000; adding G10,000 with currentC30,000 allows B20,000/C20,000 under the revised ceiling.

Actual receipts bind qualification, recipient category, year, holding status and per-item basis before aggregation. Verified crypto uses its existing calculated source vector. Known K1 amounts explicitly require the forthcoming attached-statement/basis method even when omitted from a caller's context. Complete prior histories bind identity, category, actual medium, all intervening use and opening amounts. The existing collector already supplies these facts; no new default or taxpayer-calculated carry is introduced.

Same-year B cash/noncash groups share their cap before FIFO advances. Full/zero and single-medium results are exact. Partial mixed-media attribution remains guarded. NOL, automatic/itemized prior-floor attribution, changed filing membership and specialized elections also remain separately unfinished methods. The broad ordinary K1 source block remains an internal prerequisite, not a specialized exclusion.
