# Old NOL and current charitable loss composition

This package preserves actual old regular and AMT loss histories while deriving a separate current Form172 loss from complete original income and charitable sources. The existing charitable comparison uses only the old succeeding NOL carry. A newly generated loss is added afterward and never becomes an entered allowance or a fabricated charitable reduction.

## Source, guide and output boundaries

The internal complete-history route is derived from actual packets and arrays. Unknown old history does not become empty. Old/current losses, original expiry, receipt categories and regular/AMT histories stay separate. Positive charitable benefit remains admitted only through the established unique-original-excess method. Positive benefit across multiple excess origins, prior-vintage floor attribution, partial same-category cash/property allocation and the amended prior-C offset question keep their precise guards.

The actual guide uses its existing source controls; source edits revoke confirmation, the estimate returns only after actual nested confirmations, and reload retains the originals. No computed income, deduction, loss or allocation is collected. The unmocked workspace path and separate charity/COD private contexts bind original sources before identifier redaction. Changed old balances, new loss, or balanced redistribution cannot authorize stale output.
