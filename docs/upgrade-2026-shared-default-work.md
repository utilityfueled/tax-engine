# Shared policy without an allocation agreement

This package adds the ordinary Situation4 default to the existing actual two-family policy path. It requires an explicit no-agreement answer, actual enrollment reference and taxpayer identity, confirmation that the taxpayer enrolled every original person, and original monthly coverage with actual filed-family assignments. It does not infer who enrolled people from the statement recipient alone.

The source derivation is in `spec/federal/form-8962-default-allocation.yaml`. Refreshed October26,2026: [final2025 Form8962 instructions](https://www.irs.gov/instructions/i8962), Situation4 Example2 and lines30–33, and [Reg1.36B-4](https://www.ecfr.gov/current/title-26/section-1.36B-4), (a)(1)(ii)(B) and (a)(4) Example11. The published one-of-three allocation is .33 to the claiming family and the remainder .67 to the enrolling family. The default applies the claiming ratio rounded to two decimal places, then its complement to the enrolling family. The one-of-eight tie control therefore retains .13/.87 rather than independently rounding both sides to amounts totaling more than one. This tie result is a derived interpretation of the claiming share and enrolling-remainder instructions, not an IRS published numerical example.

Each month counts only the actual covered people. The same derived fraction multiplies original premiums, correct original SLCSP and advance payments before the existing final monthly whole-dollar reporting. Original source cents and coverage remain unchanged. The guide collects enrollment evidence, leaves missing answers unknown and invalidates confirmations after edits. PartIV and the reference output identify the default method; original identifiers and private enrollment references remain outside the rendered review statement and are bound by the existing original-source token.
