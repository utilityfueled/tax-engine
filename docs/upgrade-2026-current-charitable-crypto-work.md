# Verified crypto donation carry handoff

Existing verified crypto gifts already supplied the canonical Schedule A category vector, but the 2026 current-carry calculator compared that vector against direct receipts alone. A valid combined packet therefore failed reconciliation. This package recalculates the existing crypto donation sources using the actual return year, requires their verification, and adds their exact six-category amounts only to the source-reconciliation vector. The existing common worksheet still calculates the final deduction once. It adds no crypto valuation, property election, appraisal or donor-source method.

Refreshed October 25, 2026: [IRS digital-asset FAQs 48 and 78–80](https://www.irs.gov/individuals/international-taxpayers/frequently-asked-questions-on-digital-asset-transactions), [Notice 2014-21](https://www.irs.gov/pub/irs-drop/n-14-21.pdf), [IRC170](https://uscode.house.gov/us/usc/119-120/t26/s170/), and [Publication526](https://www.irs.gov/publications/p526). Digital assets are property. The existing source calculation retains actual holding period, basis, recipient classification and substantiation. A private nonoperating foundation does not acquire the qualified-stock exception merely because a digital asset appreciated. Crypto remains noncash and cannot create a section170(p) cash deduction.
