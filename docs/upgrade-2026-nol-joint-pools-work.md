# Same-couple current joint NOL pools

This private package extends the adopted changed-filing-unit method at `a1f63cf2b28d89cda2240a4421bbaf324ad56262`. It groups the same couple's validated incoming ordinary NOL components by loss year for the current joint calculation. It retains every original source and filed owner history and reports one succeeding joint pool. It does not assign that current deduction, modified absorption, or closing balance back to owners.

## Source and calculation boundary

[Reg. 1.172-7(b), (e), (f)](https://www.ecfr.gov/current/title-26/section-1.172-7) supplies the current joint incoming-pool treatment after actual intervening owner histories. [Form 172 instructions, Change in Filing Status](https://www.irs.gov/instructions/i172) distinguish this from a new-spouse loss and its owner-income limit. The existing historical owner helper still validates original allocations, filed claims, modified absorption and attribute reductions. Monetary calculation remains Decimal; there is no entered current allowance.

An explicit original owner and a confirmed marital-year record identify the same actual pair for every relevant year. Each year reconciles to both actual returns, either the pair's joint return or two separate returns. Missing, false, duplicate or inconsistent records reject. Source IDs are unique across owners; duplicated joint-origin histories must agree and include both original owners, even a known-zero share. Regular and AMT monetary histories remain independent. Original components are sorted by source ID and pooled by loss year; original expiry and chronological limits remain unchanged. Single-source EBL/QBI treatment remains intact; a same-year EBL mixture still requires its distinct component character method.

[Reg. 1.1411-4(h)](https://www.ecfr.gov/current/title-26/section-1.1411-4) retains each original applicable fraction and uses the actual deduction. Equal-fraction, zero-use and whole-pool cases have a determined sum. The bounded source pass has not established attribution for partial use of a same-year pool with different original fractions; the code neither averages those fractions nor chooses an owner first. Full-pool rational amounts aggregate before final whole-dollar rounding. Existing joint COD allocation remains separately guarded. A later separate year still needs actual filed owner worksheets; this result is not an owner allocation for that future year.

Sources were refreshed October 27. The numerical cases are derived controls, not published matching examples or human qualification. Independent regular/AMT pooling is tested in isolated 2026 arithmetic without opening the established complete-return or PDF readiness gates.

## Derived controls and reachable output

At current limit income 60,000 and modified income 65,000, the joint post-2017 deduction is 48,000, absorption 52,000 and carry 33,000. Both source orders agree. A recurrent original joint loss retains actual historical 48,000/25,000 incoming components, rather than applying a new 60/40 ratio.

On the actual 2025 joint return with wages 100,000 and standard deduction 31,500, the regular deduction is 54,800, AGI 45,200 and carry 30,200. Independent AMT opening 20,000 yields deduction 20,000 and AMTI 80,000. At equal original investment fractions of one half, the section 1411 deduction is 27,400. Whole-pool incoming amounts of one and one at original fractions one third and one sixth aggregate to exactly one half and report one dollar. Original zero components, pre-2018 ordering and expiry are retained separately.

The real guide collects actual owners, marital years and filed use with explicit unknown/false/zero values; edits revoke confirmations. It collects no current allowance or closing shares. The private review context binds the full original input and result before I/O. The reference validates each original component exactly once and prints source-component openings plus joint totals, explicitly identifying that there is no current owner allocation. Saved physical Form 6251 uses the actual regular and AMT deductions. Actual desktop/mobile workflows edit historical absorption to 10,001, retain the distinct 10,000 historical claim, update opening to 49,999, reload and reconfirm sources, then download the joint 54,800 deduction/30,199 carry review.
